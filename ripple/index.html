How to play

  1. Read the event — which edge of the tray rises, how steeply, and for how long.
  2. Check the legend: each object and surface behaves by a few simple, consistent rules.
  3. Drag markers 1, 2, 3 to where you think each object will finally stop.
  4. Lock in. The tray tilts once, in slow motion. Each guess scores up to 100: land within about a third of a square for a perfect 100; it drops to 0 at 4½ squares away. Your daily score is the average.

No timer — take as long as you want to reason it out. One new tray every day at midnight.
